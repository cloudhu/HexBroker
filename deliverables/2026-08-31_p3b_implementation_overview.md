## 一、做了什么

把模拟盘「信号新鲜度」的度量口径从 **工作日差（`np.busday_count`）** 改为 **自然日差**，
并把阈值从 `0` 放宽到 `1`。这不是放宽风控，而是**修正 P0-3 的过度矫正**。

### 为什么必须改

旧口径把三种信息衰减完全不同的情况都算成 `fd=1`，无法区分：

| 场景 | 真实信息衰减 | 工作日差 | 自然日差 |
|---|---|---|---|
| 周一 → 周二（正常隔夜） | 1 天 | **1** | **1** |
| 周五 → 周一（跨周末） | 3 天 | **1** ❌ | **3** ✅ |
| 节前 → 节后（跨假期） | 4~10 天 | **1** ❌ | **4~10** ✅ |

为拦住 2026-08-24 事故（周五信号周一用），当年只能把阈值压到 `0`，代价是
**连正常隔夜一并误杀 → 日盘结构性零开仓**。

### 为什么阈值 0 是「不可达目标」

`ts=T` 的信号用 **T 日收盘特征**生成（`p22_tail_ext.py` L179/L182，`forecast.horizon=5`），
**T 日盘后才存在**。因此 **T 日盘中最新信号日恒为 T-1，`fd` 恒 ≥ 1** →
阈值 0 等价于「日盘永不主源开仓」。

## 四、⚠️ 关键方法论沉淀（防后人重蹈）

> **离线反事实 ≠ 实盘仿真**

首版验证直接用「当前缓存 + 历史 asof」查询，得 `asof=08-28 → fd=0`，
一度误判「信号不滞后、根因是供应链断了」。**证伪原因**：今天的缓存已含 08-28 信号，
回溯查询得到的是**事后状态**，不是 08-28 盘中的实况。

**正确做法**：按 asof 时点**截断缓存快照**后再查询。

附带排查结论：`feat[T]` 含 T 日收盘、`fwd[T]` = T→T+5，特征时点 ≤ 标签起点
→ **无前视泄露**。
