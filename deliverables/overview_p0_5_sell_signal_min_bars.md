> P0-1 冷却在此期间**封住了爆炸半径**（今日未演变为 08-24 那种数百次循环），
> 验证了 P0-1 TTL + 当日重开预算的设计价值。

### 3.2 根因链（六步）

1. sina 日线**全天不含当日**（末根恒为上一交易日；14:35 复测仍为 08-31）
2. → `recent_returns[-1]` 语义是「**昨日**已实现收益」，而非「当前波动」
3. → rb0 08-31 涨 **+2.731%**，z = **3.6411** > `s5_z`=3.0 → S5 成立
4. → 该值**全天恒定** → 一旦成立，每个 tick 重复成立
5. → **S5 无最小持仓保护**（S1 有 `s1_min_bars`，S5 只判 `len(recent_returns) >= 5`）
6. → 空仓被 `if state.position == 0: return []` 短路 →
   **开仓 tick 安全、下一 tick 爆发**，与 60s 间隔精确吻合

### 3.3 ⛔ 反直觉结论：**不改用「当日收益」口径**

影响面量化（`artifacts/_tmp/p0_5_s5_impact_scan.py`，5 品种 × 229 交易日 = 1145 样本日）：

| 口径 | 触发率 | 机理 |
|---|---|---|
| 现状（滞后一根） | **0.70%**（8 日） | r **落入** mu/sd 窗口 → z 自抑制，20 样本下 z 上界 ≈ (n−1)/√n ≈ 4.25 |
| 改「盘中实时收益」 | **2.62%**（30 日，×3.7） | r **不在**窗口内 → z 失去上界，正常波动也易超 3 |

且回测口径 `rl/futures_env._market_context` 是 `self._rets[lo:i+1]` **含当前 bar**，
与现状**分布一致、仅平移一根**。替换口径 = 破坏回测对齐 + 显著更激进。**不做。**

> 📌 **可复用判据**：z-score 类信号若把被判定点本身放进统计量窗口，z 会被自抑制且有
> 理论上界 `(n−1)/√n`；移出窗口后失去上界、触发率暴涨。改口径前**必先跑两种口径的历史触发率**。

### 3.4 修法与边界

统一门 `sell_min_bars`（缺省 2）+ 逐信号覆写 `sell_sN_min_bars`：

- S2 加 `bars_in_position >= s2_min_bars` 且 `len(recent_returns) >= 1`（顺带免疫 IndexError）
- S5 加 `bars_in_position >= s5_min_bars`
- **S3/S4 不加**：S4 本以 bars 为门；S3 用实时浮盈，不因历史序列滞后而误伤

**边界**：修复后**隔夜持仓（bars≥2）仍会被 S5 平** —— 这是日频风控的正常行为
（回测中 bar i 大涨同样当日平仓），实盘相对回测滞后一天，属可接受范围，
**不在止血阶段调阈值**（改阈值须走 walk-forward QA）。
