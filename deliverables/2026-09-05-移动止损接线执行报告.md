## 2. 盲区根因实证（改前）

逐文件取证（非凭记忆）：

- `hexbroker/risk/manager.py:136-145`：`evaluate` 每 tick 调 `trailing_stop()` 算出 `decision.stop_price`（ATR 三档 ratchet，只增不减，随价移动锁定利润）。
- `hexbroker/paper/planner.py:111,129`：`update_from_signal` 读 `decision.stop_price` → `plan.stop_price`。
- `hexbroker/paper/broker.py:177-193`：`execute_plan` **仅在开仓（`abs(current)<1e-12`）与反手时**写 `self._stops[symbol] = plan.stop_price`；**持仓期间的加减仓/持有分支完全不更新 `_stops`**。
- `hexbroker/paper/scheduler.py:952-963`：`_shadow_stop_sweep` 读 `broker.stop_of(symbol)`（=`_stops[symbol]`）交 `ShadowStopMonitor` 比较；命中后**仅当 `not monitor.enabled`（即 `shadow_stops:false`）才 `_force_flat_on_stop`**。

**结论**：ATR trailing stop 的值在开仓瞬间进入 `_stops` 后便被冻结；持仓期间价格上下波动，`_stops` 纹丝不动 → 所谓「移动止损」从不移动，影子监视器永远拿一个陈旧冻结值做比较。这就是盲区全部根因，**无需新增比对逻辑**——只需让 `_stops` 每 tick 跟上 `decision.stop_price`。

## 3. 接线方案与代码改动

### 3.1 `hexbroker/paper/broker.py`（+27 行）
新增 `PaperBroker.set_trailing_stop(symbol, stop_price)`（位于 `take_profit_of` 之后）：
- 仅当 `abs(self._broker.position(symbol)) > 1e-12`（有持仓）才写 `self._stops[symbol]`；
- `None` / 非浮点 / `<=0` / `NaN` → 幂等 no-op（不向空仓注入幽灵档位，不污染 `account.json` 与影子扫描）；
- **只写 `_stops`，不产生成交、不改持仓、不动现金/权益**（与 `execute_plan` 开仓写入是两条独立路径，互不覆盖）。

### 3.2 `hexbroker/paper/scheduler.py`（+13 行，两处）
- `_process_symbol`（决策 `decision = self._risk_gate.evaluate(...)` 之后）：
  ```python
  _stop = getattr(decision, "stop_price", None)
  if _stop is not None and abs(self._broker.position(symbol)) > 1e-12:
      self._broker.set_trailing_stop(symbol, _stop)
  ```
- `_risk_manage_only`（accumulate / c0 仅风控路径）同样两行。
- 用 `getattr(decision, "stop_price", None)` 防御：决策对象可能缺该属性（mock/旧路径），避免 `AttributeError`（见 §4 回归）。

## 5. 行为语义（接线后）

| 场景 | 接线前 | 接线后 |
|---|---|---|
| 持仓期间 `_stops` | 冻结在开仓价 | **每 tick 跟随 `decision.stop_price` 移动** |
| 影子监视器比较基准 | 陈旧冻结值 | **最新 trailing 值** |
| `shadow_stops:true`（默认） | 只记录（旧值） | 只记录（**真实移动值**，观察质量提升） |
| `shadow_stops:false` | 平冻结值击穿 | 平**真实移动值**击穿（真实平仓） |

即：接线让「移动止损」名副其实地**移动**并被正确观察；真实平仓出口早已就位（`_force_flat_on_stop`），由配置开关控制。
