## 3. 误判根因（方法论教训，已固化）

「静默死亡第二例」的误判来自把两个正常现象叠加成了事故：

1. **可见性盲区**：CREATE_NEW_CONSOLE 实例的 stdout/stderr 不落盘，进程退出后无日志可查 → 误以为「静默」。
2. **生命周期假设错误**：以为单进程全天运行，实际是**分时窗口各自启动实例**（早盘 08:55 / 午盘 13:25 / 夜盘 20:55 三套 launch 日志），早盘实例在午盘前退出属设计内接力。
3. **锁语义误解**：P1-C 后 pid 文件常驻、进程退出 OS 自动释放句柄锁 → `paper.pid` 有内容 ≠ 有活进程 ≠ 僵尸锁。

**已固化的正确判据**（见 MEMORY.md）：判进程存活必须 `Get-Process -Id <pid>`（Git Bash `ps aux` 查不到 Windows python 进程是假阴性）；判「异常死亡」必须同时排除 watchdog 正常退出语义 + 分时窗口生命周期 + P1-C 锁语义，三条缺一不可。
