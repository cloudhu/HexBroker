# 品种池扩展 + RL 状态增强报告（2026-08-17）

> **任务（P1 三件套）**：①品种池 3→6（+cu0 沪铜/rb0 螺纹/i0 铁矿，PandaData 全历史）；②更长 valid 分段（3 子段 118/128/65 天交叉）；③RL 状态增强（obs 12→36 维：+横截面 rank + 短窗口 vol5）。

| 项 | 内容 |

## 三、结论（诚实分级）

1. **三项提升边际有限**：Sharpe 0.36 → 0.38（+0.02）——品种池/状态/valid 未带来质变，**印证 RL 决策层"弱正 + 稳健优于基线"的本质**（非数据不足所致）；
2. ✅ **统计稳健性提升**：OOS 信号 288 → 592（×2）——0.38 在更大样本下更有意义；
3. ✅ **相对基线优势保持**：RL 0.38 vs 规则基线 6 品种 -0.27（同段）——RL 仍优于基线；
4. ⚠️ 回撤放大（-6.5%）：2 档满仓动作更激进（0/1 无中间档）；
5. ⚠️ cu/rb/i 数据至 2026-02（网关 1000 行限制）——OOS 段后 5 个月仅 3 品种（已标注）。

## 四、主理人裁决建议

1. **采纳**：6 品种池 + 状态增强 + 交叉 valid 为 SENTINEL 标准配置（统计更可靠）；
2. **RL 最终定位确认**：OOS Sharpe 0.38（592 信号）——**弱正、稳健优于基线**；作为规则基线的辅助增强层，不做独立主策略；
3. **P2 后续**：动作 3 档（0/0.5/1）在 6 品种下需动作空间压缩（分组决策）；cu/rb/i 数据补齐 2026-02 后段；状态加持仓期结构。
