# 多分段 valid 交叉选择报告（2026-08-17）

> **任务**：进化适应度从单一 valid 段改为多子段交叉平均，缓解对单一 valid 段结构的过拟合。
> **结果**：OOS（BacktestEngine 完整口径）从 -0.02 → **+0.36**——交叉选择有效，RL 真实水平定为弱正（Sharpe ~0.36、年化 0.70%、回撤 -3.0%）。

---

## 一、方法

- valid 段（2022~2024-07-17）拆 3 子段（按年份），过滤后保留 **2 段（66+64 天）**；
- 适应度 = 各子段 BacktestEngine 回测 Sharpe 的**交叉平均**——权重需在多个子段同时表现好；
- OOS（2024-07-18~2026-08 真新数据）完全留出，不参与任何选择。

## 二、结果（BacktestEngine 完整口径 OOS）

| 进化选择方式 | OOS 年化 | OOS 回撤 | OOS Sharpe |
|---|---:|---:|---:|
| 单一 valid 段 | -0.04% | -3.8% | -0.02 |
| **多分段交叉（本次）** | **+0.70%** | **-3.0%** | **+0.36** |
| 规则基线同段 | -0.13% | -3.1% | -0.13 |

**进化轨迹**（交叉平均 Sharpe）：G1 0.527 → G2 0.315 → G3 0.512；最优 **w=[0.1, 0.01, 2.511]**（低 pnl 权重、几乎无换手惩罚、高趋势惩罚——极度保守策略）。

## 三、结论

1. ✅ **多分段交叉选择缓解过拟合有效**：同口径下 OOS -0.02 → +0.36——权重不再只在一个子段上"取巧"；
2. **SENTINEL RL 最终真实水平**：**OOS Sharpe ~0.36 / 年化 0.70% / 回撤 -3.0%**——弱正收益、低回撤、优于规则基线同段（-0.13%）；
3. 最优策略形态：极度保守（高趋势惩罚 → 几乎只在强趋势中持仓）——与规则基线"重趋势过滤"精神一致；
4. ⚠️ 样本限制：valid 交叉仅 2 段（130 天）——交叉选择统计强度有限；**绝对水平仍弱**（Sharpe 0.36 不算强，仅"可用且稳健优于基线"）。

## 四、主理人裁决建议

1. **采纳**：多分段交叉选择为进化标准协议（缓解过拟合）；
2. **SENTINEL RL 定位**：OOS 弱正（Sharpe 0.36）——可作为规则基线的**辅助增强**（趋势段叠加），不作为独立主策略；
3. **P1 提升**：扩展品种池（截面信息更足）→ 更长的 valid 分段（更多子段交叉）→ RL 状态增强；
4. **风险**：0.36 的 Sharpe 在统计上仍不显著（OOS 仅 288 信号）——需更长 OOS 或更多品种确认。
