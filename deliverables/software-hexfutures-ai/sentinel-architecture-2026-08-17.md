# SENTINEL 架构设计：State-gated Evolutionary Neural Trading with Intensity-Ordered Learning（2026-08-17）

> **任务**：汲取模型探索全部经验，重新架构一个前所未有的模型（非开源模型调参/训练），目标全面提高准确率→提升年化收益，融合强化学习与自回归进化。
> **探索经验输入**（2026-08-16 全链实验）：
> ① 方向二元预测≈随机（嵌套口径 49.5-53.4%）；② 真实 alpha 在 exp_ret **强度排序**（Q4-Q0 价差 0.688%/5日）；③ **看空反指**（p_up<0.4 实际涨 53.6%）；④ **截面 alpha > 时序 alpha**（品种内排序≈0）；⑤ 趋势过滤有效（Sharpe 0.85→1.21）；⑥ 时间不持续（2021/2024 失效）；⑦ 校准幻觉（评估必须嵌套口径）；⑧ 品种分化（m0 强/ag0 次/au0 无）。

---

## 一、设计原则（经验 → 架构）

| # | 探索经验 | 架构编码 |
|---|---|---|
| 1 | 方向预测≈随机 | 目标函数**弃用方向分类**，用强度排序（learning-to-rank） |
| 2 | 强度排序有真实 alpha | L1 输出**截面相对强度分数**（pairwise 排序损失） |
| 3 | 看空反指 | **非对称**：L3 奖励对做空惩罚、决策层只输出多头仓位 |
| 4 | 截面 > 时序 | 输入横截面标准化 + 跨品种相对特征 |
| 5 | 趋势过滤有效 | L2 状态门控**内置于模型**（趋势/波动作为条件输入） |
| 6 | 时间不持续 | 自回归进化周期重估 + 状态条件化 |
| 7 | 校准幻觉 | 所有评估/进化适应度一律**嵌套口径** |
| 8 | 品种分化 | RL 组合层在品种间分配（学习 m0/ag0 权重） |

## 二、四层架构

```
┌─────────────────────────────────────────────────────────┐
│ L4  EvoLoop：自回归进化（ExAMM 引擎）                     │
│     进化对象：L1 超参/特征子集 + L3 奖励权重 + L2 门控参数  │
│     适应度：嵌套口径完整回测 Sharpe（防幻觉）              │
├─────────────────────────────────────────────────────────┤
│ L3  RLDecision：RL 决策层（自研 PPO + FuturesTradingEnv） │
│     状态 = L1 强度分数 + L2 状态 + 持仓 + 成本             │
│     动作 = 三品种连续多头仓位 [0,1]（非对称：无做空）       │
│     奖励 = 实现收益 − 成本 − 状态惩罚                      │
├─────────────────────────────────────────────────────────┤
│ L2  StateGate：状态门控                                   │
│     趋势（MA5/MA20 关系）、波动率、截面动量 → 条件特征/门控 │
├─────────────────────────────────────────────────────────┤
│ L1  IntensityRanker：强度排序器（自研轻量排序网络）        │
│     输入 = 现有特征 + 横截面 z-score                      │
│     输出 = 截面相对强度分数（pairwise 排序损失，纯 numpy） │
└─────────────────────────────────────────────────────────┘
```

## 三、L1 IntensityRanker（本任务 Phase 1 核心）

**为什么是它**：经验②③④表明模型唯一稳健的 alpha 来源是截面强度排序——排序学习目标直接优化它，而非绕道回归/分类。

- **网络**：自研纯 numpy MLP（隐藏层 2×64，tanh），**非开源模型**；
- **目标**：RankNet pairwise 损失——对同一交易日截面内任意 (i,j) 对，惩罚实际收益排序与预测强度排序不一致（σ=1 logistic 概率）；
- **输入**：现有特征子集（f_* 列）+ 品种内 z-score 标准化（截面可比）+ 状态特征（L2 先行并入）；
- **训练**：walk-forward 分折训练（与 LightGBM 相同切分，嵌套评估）；
- **输出**：截面强度分数 s_i = σ(z_i) → 替代 exp_ret 用于 top-K 做多。

**Phase 1 验证问题**：排序目标 vs 回归目标（LightGBM exp_ret），在嵌套口径下 Q4-Q0 价差/排序 IC 是否更优？**这是新架构的单点可行性验证**。

## 四、L3 RLDecision（Phase 3）

- 增强 `FuturesTradingEnv`：状态向量 = [L1 强度分数(3), L2 状态(3×2), 持仓(3), 成本余量]；
- 动作 = 连续 3 维 [0,1]（各品种多头仓位），**动作空间不含做空**（经验③）；
- 奖励 = Σ(仓位×价格收益×名义) − 交易成本 − λ×仓位切换惩罚（换手率控制）；
- 算法：复用自研 `train_ppo`（纯 numpy，CPU 沙箱可用）。

## 五、L4 EvoLoop（Phase 4）

- 用 `examm_engine`（RNN 基因组 + 结构变异）进化：L1 隐层/特征子集/学习率 + L3 奖励权重 + L2 门控窗口；
- 适应度 = 嵌套口径完整回测 Sharpe（含成本）——**直接优化最终目标**；
- 自回归性：ExAMM RNN 可并行进化为"直接预测强度"的时序路径（备选 L1）。

## 七、风险与护栏

- **过拟合防线**：所有阶段评估/进化适应度 = 嵌套口径（cal_split=0.5）+ 样本外分段确认；
- **纯 numpy 自研**：MLP/RankNet 手写梯度，不引入新依赖（符合"前所未有"与 CPU 沙箱约束）；
- **失败判定**：Phase 1 若排序目标不优于回归目标（嵌套口径），停止 L1 路线并回退集成方案（L3 直接用 exp_ret + 状态）。

## 八、Phase 1 实验结果（2026-08-17 上午，已执行）

**RankNet 强度排序器 vs LightGBM exp_ret（跨品种合并训练，嵌套口径）**：

| 指标 | LightGBM exp_ret（回归目标） | RankNet 分数（排序目标） |
|---|---|---|
| Q4-Q0 价差/5日 | **0.700%** | 0.320% |
| RankIC | +0.0123 | **+0.0296** |

**裁决**：排序目标在 Q4-Q0 极端分位价差上未胜出（回归目标更强），但全局排序质量（RankIC）更优。按架构失败判定逻辑：
- **L1 信号源**：采用已验证更强的 **LightGBM exp_ret**（0.700%）作为强度信号；
- **RankNet 排序目标**：降级为 L4 进化候选（进化可对比选择）；
- **重心转向 L3 RL 决策层**（非对称多头决策 + 组合分配 + 状态条件化）——Phase 3 启动。
