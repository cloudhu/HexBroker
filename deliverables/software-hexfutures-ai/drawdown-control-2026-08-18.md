# P2 回撤控制（2026-08-18）

**TL;DR**：在最优配置（v1 分组剔 p0 17 品种 + 0.8·exp + 0.2·mom90 + top35% + W20-linear 监控）上验证三类风控——**止损无效（几乎不触发）、熔断有害（误伤反弹）、波动率目标有效**。**采纳波动率目标 17.5% 为部署级配置**：全样本回撤 **-26.1% → -18.3%**（-30%），Sharpe 0.98→0.94（仅 -4%），年化 14.31%（-15%）。

| 变体 | 机制 |
|---|---|

| B1/B2/B3 止损 | 持仓后价格相对入场回撤 -5%/-8%/-10% → 次日 target=0 |

## 三、核心结论

1. **止损否决（B）**：持仓周期短（5 日 horizon 信号、逐日调仓）+ 监控已挡趋势段，-5~10% 止损**几乎不触发**（持仓 1025→1017，仅减 8 手）——逐位等价，纯增加实现复杂度；
2. **熔断否决（C/E）**：等权组合指数熔断**误伤严重**——触发后空仓错过反弹，Sharpe 0.98→0.61~0.77、回撤反而恶化（-27.8~-28.4%）——与 P0-1 监控（价差驱动、精确）不同，粗粒度回撤熔断是负贡献；
3. **波动率目标采纳（D17.5%）**：**回撤 -26.1% → -18.25%（-30%）、Sharpe 0.98→0.94（仅 -4%）、年化 -15%**——用少量收益换大幅回撤收敛，**权衡曲线平滑（12.5/15/17.5 单调）非尖峰**；
4. **机制**：波动率目标在高波动期（2022 商品熊）自动降仓，恰好覆盖监控未覆盖的"同向波动放大"风险维度——与信号监控（有效性门控）正交互补。

## 四、诚实标注

- **OOS Sharpe 略降**（0.39→0.24）：OOS 段本身低波动（回撤仅 -3.4%），波动率目标 scale≈1 无增益——该风控的价值集中在全样本高波动段，OOS 段是"无伤"而非"增益"；
- 基线数字与历史最优（0.99）差异 0.01 源于缓存重建后数值微差（v1 原版被覆盖，v2 为 IC 等价副本），口径一致；
- D17.5 的绝对回撤 -18.25% 仍高于"极致保守"标准（<15%），若追求更低回撤可选 D15（-15.5%，Sharpe 0.89）。

## 五、部署级配置（项目终态 v2.0）

```
v1 分组建模信号（剔 p0，17 品种）
score = 0.8 × rank(exp_ret) + 0.2 × rank(mom_90)

+ 波动率目标 17.5%（组合 20 日滚动年化波动 → scale）
名义 30%
→ 全样本年化 +14.31% / 回撤 -18.25% / Sharpe 0.94
→ OOS 年化 +0.48% / 回撤 -2.87% / Sharpe 0.24
```
