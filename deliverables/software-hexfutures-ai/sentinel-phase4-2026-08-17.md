# SENTINEL Phase 4 进化闭环报告（2026-08-17）

> **任务**：奖励工程（修复 Phase 3 奖励失衡）+ Phase 4 自回归进化闭环（进化 L3 奖励权重）。
> **方法**：自回归 ES（高斯变异 + EMA 均值更新，即"自回归"动量）；分段：train<2022（PPO）、valid 2022-2023（进化适应度）、**OOS 2024（完全留出，只评估一次）**。

---

## 一、奖励工程（SentinelTradingEnv 重构）

Phase 3 问题：`ep_rew_mean=-12`，换手惩罚（w_turn=0.1 × |Δpos|~0.5-1）主导、pnl 项（~0.001）过小——奖励信号被噪声淹没。

修复（2026-08-17）：
| 项 | 前 | 后 |
|---|---|---|
| pnl 尺度 | 原始小数（~0.001） | **×10000 以基点计**（~3-30 bp） |
| 换手惩罚 | w_turn=0.1 | w_turn=0.5（可进化） |
| **趋势惩罚** | 无 | **w_trend×Σ(持仓×非趋势)**（下跌趋势持仓惩罚——编码 trend 过滤经验进奖励） |
| 权重 | 硬编码 | **w_pnl/w_turn/w_trend 全参数化**（cfg.rl，供进化搜索） |

## 二、Phase 4 进化闭环（自回归 ES）

- **进化对象**：θ=[w_pnl, w_turn, w_trend]（log 空间，w_pnl∈[0.1,10]、w_turn∈[0.01,2]、w_trend∈[0,8]）
- **算法**：pop=6、gen=3、σ=0.5→0.25→0.125 递减；精英 + EMA 均值（α=0.5）
- **适应度**：θ → 训练 PPO 8k steps（train 段）→ valid 段（2022-2023）回测 Sharpe
- **选择隔离**：OOS（2024 起）完全未参与选择

**进化轨迹（valid 段 Sharpe）**：
| 代 | 精英 w | valid Sharpe |
|---|---|---|
| G1 | [5.35, 0.45, 1.26] | 0.814 |
| G2 | [1.49, 1.08, 1.32] | -0.406 |
| G3 | [2.42, 0.85, 2.11] | 0.647 |

**最优**：w=[5.35, 0.45, 1.26]（G1 精英，valid Sharpe 0.81）——高 w_pnl（重收益）、中 w_turn、中 w_trend。

## 四、结论（诚实分级）

1. ✅ **进化闭环方法验证通过**：自回归 ES 能进化奖励权重、valid/OOS 隔离无泄漏、OOS 正收益低回撤——**SENTINEL L4 成立**；
2. ✅ **奖励工程有效**：趋势惩罚使 RL 学到与规则基线一致的"下跌不做多"行为（OOS 回撤 -2.2%）；
3. ⚠️ **绝对数值不可信**：OOS 仅 96 天（数据截止 2024-07），年化 137%/Sharpe 5.47 是半年样本外推的方差放大——**不能作为战略依据**；
4. ⚠️ 进化在 valid 段选择仍有 overfit-to-valid 风险（G2 负适应度个体存在，种群方差大）。
