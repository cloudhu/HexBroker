# Raw Alpha 诊断报告：53.37% 方向准确率的真实性与结构（2026-08-16）

> **背景**：嵌套验证发现现口径 70.23% 含 ~20.7pp 校准幻觉，raw p_up 无校准口径 ~52-53%。本报告全 66 折跑 `calibration=none`，从 7 个维度判定 raw 信号是否含真实信息。
> **方法**：`scripts/diagnose_raw_alpha.py`（n=2046 raw 信号，200 次随机对照）。

---

## 一、核心结论（TL;DR）

**✅ raw p_up 含统计显著的真实 alpha，但结构与直觉不同：**

1. **总体显著**：方向准确率 **53.37%**（95%CI [51.2%, 55.5%] 不含 50%，二项检验 p=0.0012；随机标签对照 200 次零假设 p95=52.49%，观测在 **2.0% 分位** → 拒绝噪声假设）；
2. **真实信息在「收益强度排序」而非「方向阈值」**：期望收益 exp_ret 分位 Q0→Q4 的实际收益 **-0.20% → +0.70% 完美单调**（0.9pp/5 日价差），raw RankIC 全期 +0.056（2019-2023 稳定正）；
3. **看多可用、看空反指**：p_up>0.6 组（n=1130）实际上涨 57.4% ✅；p_up<0.40 组（n=750）实际**上涨 53.6%** ❌——模型"预测下跌"是反指；
4. **alpha 集中在 ag0/m0，au0 无**：ag0 54.69%（p=0.008）、m0 55.57%（p=0.002）、au0 49.85%（p=0.55）；
5. **时间不持续**：2020（56.5%）、2023（56.2%）强；2021（49.4%）、2024（48.9%）为负——随市场状态波动。

## 三、解读：为什么方向准确率低但收益排序高

1. **阈值截断丢信息**：p_up>0.5 的二元判断把 exp_ret 的连续排序信息压缩为方向；模型学到的核心是**收益强度**（Q4 vs Q0 单调 0.9pp），方向判断只是其弱投影；
2. **看空反指的原因**：2018-2024 商品整体偏多（通胀/供给周期），"预测下跌"的尾部信号实际多数反弹——**看空侧不可用**；
3. **au0 无 alpha**：黄金受美元/避险驱动（外盘 uup 已有部分捕获），与 ag/m 的工业/商品属性不同，需差异化；
4. **2021/2024 失效**：2021 商品冲顶回落、2024 高位震荡——趋势类信号在震荡/反转市失效，符合商品期货特征。

## 四、主理人裁决建议

| 优先级 | 建议 | 依据 |
|---|---|---|
| **P0** | 信号设计转向 **exp_ret 分位/强度**而非 p_up>0.5 二元方向（Q4-Q0 价差 0.9pp/5 日可交易）；评估指标增加 exp_ret 分组单调性 | E 维强证据 |
| **P0** | **看空信号禁用**（反指）——只取高置信看多（p_up>0.6 组 57.4%）或 exp_ret 高位组 | D 维证据 |
| **P1** | au0 单独评估/剔除（无 alpha 拖累总体）；ag/m 为主战场 | B 维证据 |
| **P1** | 评估协议固化嵌套口径（cal_split=0.5）作为标准；历史指标加注 | 上一轮发现 |
| **P2** | 诊断 alpha 时间不持续（2021/2024 失效）——市场状态过滤器（如趋势/震荡判据）可叠加 | C 维证据 |

**总体判定**：模型**不是随机**——它学到了收益强度排序（真实 alpha），但"5 日方向二元判断"是低效的信号形态。**方向性战略调整：从"方向预测"转向"强度排序 + 单边多头"**。
